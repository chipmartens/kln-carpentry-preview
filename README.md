# KLN Carpentry, website preview

A brand and website proposal for **KLN Carpentry** (Kelvin Neufeld, Steinbach MB),
prepared by Chip Martens. Static HTML, no build step, no dependencies.

**This is a preview, not a live site.** Every page carries `noindex,nofollow` and the
repo serves a `robots.txt` that disallows everything, so it cannot compete with
klncarpentry.ca in search. The URL is unlisted but public to anyone who has it.

Photographs are Kelvin's own, from klncarpentry.ca and @klncarpentry.
